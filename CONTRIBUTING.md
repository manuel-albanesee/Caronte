# Contributing to Caronte

Bug reports, usage feedback, and proposals are welcome. Please use synthetic
examples and omit logs, telemetry, secrets, and proprietary code.

Manuel Albanese maintains the original Caronte materials and grants commercial
runtime licenses. A patch containing original third-party material can be
accepted only after the maintainer and the contributor have signed an
agreement that transfers the necessary copyright to the maintainer to the
extent permitted by applicable law. Opening a pull request alone does not
transfer ownership. Contact the maintainer before submitting a code patch.
The bundled MIT materials remain separately licensed as described in
[NOTICE.md](NOTICE.md).
